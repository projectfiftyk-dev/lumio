# Lumio

An audiovisual interactive learning platform where stories teach 
and characters remember.

Learners progress through episodic narrative experiences — 
making choices, interacting with AI characters, and acquiring 
language and knowledge through immersion rather than repetition.

## Verticals
- **Lumio for Languages** — immersive language acquisition through story
- **Lumio for Kids** — interactive audiovisual storybooks
- **Lumio for Learners** — narrative-driven subject learning

## Stack
- **Frontend** — React + TypeScript (Vite)
- **Backend** — Java Spring Boot
- **Database** — PostgreSQL
- **Storage** — MinIO (S3-compatible)
- **Cache** — Redis

## Structure
